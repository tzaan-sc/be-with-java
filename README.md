## 📂 Cấu trúc một Phase học tập

Mỗi thư mục giai đoạn được chuẩn hoá gồm 2 phần:

```text
xx-ten-giai-doan/
├── README.md               # Tổng quan giai đoạn, mục tiêu & checklist bài học
├── theory/                 # Ghi chép lý thuyết chi tiết theo từng Chapter
│   ├── chapter-01-...md
│   └── chapter-02-...md
└── exercises/              # Code bài tập thực hành / Dự án mẫu
```

---

## 💡 Phương Pháp Học Hiệu Quả
1. **Lý thuyết ngắn gọn:** Đọc hiểu và viết tóm tắt lại bằng lời của mình vào file Chapter trong `theory/`.
2. **Code tay trực tiếp:** Không copy-paste, tự gõ lại và debug lỗi trong thư mục `exercises/`.
3. **Trả lời câu hỏi phỏng vấn:** Mỗi chapter đều có phần câu hỏi trọng tâm thường gặp khi đi phỏng vấn.
